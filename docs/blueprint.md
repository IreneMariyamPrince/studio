# **App Name**: ExpenseWise

## Core Features:

- TailAdmin Integration: Integrate TailAdmin dashboard for user interface and overall application structure.
- Expense Management: Implement a system for managing company expenses, including tracking, categorization, and reporting.
- Invoice Builder: Build an invoice builder module with customizable templates and support for generating and managing invoices.
- Chart of Accounts: Implement a chart of accounts feature for categorizing financial transactions.

## Style Guidelines:

- Primary color: Use Tailwind's default blue hues for primary actions and branding.
- Secondary color: Light gray backgrounds (#F7FAFC) to provide visual separation.
- Accent: Teal (#4DC0B5) for highlights and interactive elements.
- Clean and modern sans-serif fonts for readability and a professional look.
- Use a consistent icon set (e.g., FontAwesome or Remix Icon) for visual cues.
- Responsive layout design to ensure compatibility across devices (desktop, tablet, mobile).
